# 🟡 Falling Sand Simulator

Simulation of falling sand in C# using [Raylib-cs](https://github.com/ChrisDill/Raylib-cs).

## 🧱 Requirements

- [.NET SDK 6.0+](https://dotnet.microsoft.com/download)
- [Raylib-cs](https://www.nuget.org/packages/Raylib-cs)

## 🚀 Run

```bash
dotnet run

# Or in watch mode

dotnet watch run
```
